# PokkaTomo

一個專屬於你的網頁版小夥伴 PokkaTomo（ポッカとも）。
可以用說的、也可以用打字的跟它聊天；它會記得你們聊過的事、每天寫日記、主動跟你打招呼，
胸口的小燈會隨心情變色。晚上打開會變成想睡覺的樣子，點一下它還會有反應喔。

> 這份文件是給「使用」PokkaTomo 的人看的。如果你是要修改程式碼的開發者，
> 請改看 [`AGENTS.md`](./AGENTS.md)（入門）與 [`README_TECH.md`](./README_TECH.md)（技術細節）。

## 怎麼開始使用

1. 把整個資料夾（或收到的 `pokkatomo-apple-bundle.zip` 解壓縮後的資料夾）放到「文件」或「桌面」都可以。
2. 資料夾裡找到 **`start-pokkatomo.command`**，**雙擊它**。
   - 第一次雙擊可能會跑一兩分鐘（在準備東西），中間**不要關掉跳出來的黑色視窗**。
   - 如果 macOS 說「無法打開，因為來自未識別的開發者」：在 Finder 裡對這個檔案「按右鍵 → 打開」，
     再點一次「打開」確認即可，只有第一次需要這樣。
3. 準備好之後，瀏覽器會自動打開一個網頁，就可以開始跟 PokkaTomo 說話了。
   - 按住畫面下方的麥克風按鈕說話，放開就會送出。
   - 瀏覽器第一次會問「要不要允許使用麥克風」，選允許。
4. 之後每次要用，一樣雙擊 `start-pokkatomo.command` 就好，會很快，不用重新安裝。
   如果上次忘記關、PokkaTomo 其實還開著，也不用自己去找、去關掉——雙擊會自動把舊的換成新的。
   收到新版本的程式之後也一樣直接雙擊，它會自己發現有更新、重新準備一次畫面。
   - **想要一開電腦就自動打開**：雙擊一次 **`autostart-on.command`**。以後登入這台 Mac 時，PokkaTomo 會自己啟動並用 Chrome 打開。
     第一次 macOS 可能會問「終端機想要控制 System Events」，按「好」。不想要了就雙擊 `autostart-off.command`。
5. 想要完全關閉 PokkaTomo：雙擊 **`stop-pokkatomo.command`** 就好（或直接重新開機），不用打開「活動監視器」。
6. 如果雙擊之後跳出「PokkaTomo 沒有成功啟動」，把那個黑色視窗截圖傳給開發者就好。

## 打開之後

- **密碼**：第一次打開會請你設定一組四位數密碼（輸入兩次）。之後每次打開、或放著 15 分鐘沒動，都要輸入密碼。
  密碼是用來避免別人打開畫面看到你們的對話。連續輸錯 5 次要等 1 分鐘。
  想改密碼：⚙️設定 → 密碼。忘記密碼的話請找開發者重設（對話和日記不會不見）。
- **選角色**：輸入密碼後選今天要跟誰聊天。第一次打開（或全部刪掉之後）沒有任何角色，會直接出現「新增角色」的畫面，程式不會自己先建一隻。可以按「＋ 新增角色」多養幾隻（取名字、選說話的語言、樣子和毛色）。新角色是全新的一隻：稱呼預設「主人」（選日文就是「ご主人さま」）、個性是預設的（選日文就是日文的），喜好、紀念日、城市都是空的，要在設定裡自己填。
  每個角色有自己的對話、日記、親密度，互相不知道對方聊過什麼；設定（怎麼稱呼你、喜好、紀念日、城市、聲音）也是每個角色各自的。
  **說話的語言**在新增角色時選，之後不能改（稱呼、個性、日記都跟著它）；例如一隻說中文、一隻說日文。
  聊天中想換角色：按左上角的名字。
  **排順序**：按住卡片左上角的 ⠿ 拖到想要的位置（手指、滑鼠都可以），最前面那隻是預設的角色。
  **不要的角色可以刪掉**：卡片右上角的 🗑 → 輸入密碼確認。牠的對話、日記、親密度會全部刪掉，**沒辦法復原**。最後一隻也可以刪，刪完會回到「新增角色」的畫面。

## 畫面上可以做什麼

- **按住麥克風說話**，放開就會送出；也可以點旁邊的⌨️切換成打字輸入。
- **文字對話平常是隱藏的**（主要用說的）：角色說的話會像漫畫一樣，用對話泡泡從牠頭旁邊冒出來，講完一會兒就消失。
  不想看泡泡、只想聽聲音：按右上角 🔊 旁邊的 💭。想看完整的文字對話，按麥克風上面的「💬 顯示文字對話」，
  打開之後旁邊會多一個「🕘 今天稍早的對話」，可以看今天之前聊過的。
- **點一下角色**，牠會有反應，跳出一個小對話泡泡。摸不同地方反應不一樣：摸頭會很開心、
  戳臉頰會臉紅、摸耳朵耳朵會抖、戳肚子（胸口的愛心燈）會怕癢笑出來、握手會揮手、碰腳會跳一下、
  摸尾巴會害羞地搖尾巴。只有點到角色身上才算，點旁邊空白不會有反應。
- PokkaTomo 正在講話時點牠，牠會先停下來，不用等牠講完才能說下一句。
- **右上角的按鈕**分成兩群：左邊是功能（天氣、🔮占卜、💝記得的事、📔日記），右邊是設定（🌐語言、🔊聲音、💭泡泡、⚙️設定）。
  畫面比較窄的時候，設定那一群會收進一個 **🎛️** 按鈕，按一下就會在下面展開，再按一次（或點旁邊）就收起來。
- **右上角🌐按鈕**：切換畫面上顯示的文字（中文／日文）。只換介面，角色說話的語言不會變。
- **PokkaTomo 會主動打招呼**：早上、下午、晚上、深夜第一次打開（或離開一陣子再回來）時，
  牠會先開口，有時候還會問起前幾天聊過的事。
- **胸口的心情燈**：顏色代表 PokkaTomo 現在的心情——黃色開心、粉紅色喜歡、綠色平靜、
  藍色難過、紫色擔心、水藍色驚訝。你說難過的事，牠也會跟著難過、講話變慢一點。
- **右上角💝按鈕**：「牠記得的事」。最上面可以打關鍵字搜尋，下面是牠記住的「你喜歡的東西」和「重要的日子」，
  記錯的可以按 ✏️ 改、按 🗑 讓牠忘掉。打了關鍵字時，還會列出你們聊天時提過這個詞的話。
  牠平常會把這些放在心上，只有聊到相關的事才會提起。
- **右上角📔按鈕**：PokkaTomo 的日記，用月曆的方式呈現。點某一天，下面可以切換「📖 日記」和「💬 對話」，
  看那天牠寫的日記、或那天你們說過的每一句話。牠每天會用自己的口吻把你們聊過的事寫下來，
  有日記的日子會染上牠那天的心情顏色，♥ 是紀念日、⭐ 是你們第一次聊天的那天；
  點任何一天就能看那天的日記，‹ › 可以翻到之前的月份。也可以按按鈕請牠現在就寫今天的。
- **天氣**：在設定裡填你住的城市，右上角會顯示現在的天氣，PokkaTomo 也會在適合的時候
  提醒你帶傘、多穿一點（需要有網路；沒網路也不影響聊天）。**按一下右上角的天氣**，
  會打開接下來 24 小時每個小時的天氣（溫度、會不會下雨），再按一次就收起來。
- **之前的對話**：每次打開畫面都是乾淨的，不會一直看到以前的聊天。想回頭看今天聊過什麼，
  先打開文字對話（💬），再按旁邊的「🕘 今天稍早的對話」。更早的日子到📔日記的「💬 對話」頁籤看。
- **角色的聲音**：⚙️設定裡可以替每個角色選聲音、調高低和快慢，按「試聽」先聽聽看。
  標 ★★★ 的最像真人。如果清單裡沒有 ★★★ 的聲音，可以在 Mac 的「系統設定 → 輔助使用 → 朗讀內容 → 系統聲音 → 管理聲音」
  下載中文的「美佳（優化）」或日文的「Kyoko（優化）」「O-ren（Premium）」等（免費），重新整理網頁後就會出現。
- **右上角🔊按鈕**：關掉／打開 PokkaTomo 的聲音（在外面或半夜不想吵到人時，只看文字就好）。
- **右上角⚙️按鈕**：打開設定，可以幫牠取名字、改牠怎麼稱呼你、牠的個性、你住的城市、你的喜好、
  重要紀念日、牠的樣子（全身／舊版圓圓的）。取了名字之後，畫面上所有地方都會跟著改（不填就叫 PokkaTomo／ポッカとも）。
  聊天時 PokkaTomo 自己記住的喜好也會出現在這裡，不想讓牠記的可以直接刪掉。
- **紀念日**：設定好的紀念日當天（或前三天內），一打開 PokkaTomo 牠就會主動提起。
- **跟牠說早安、我出門了、我回來了、晚安**：牠都會好好回應。說「我出門了」，回來打開畫面時牠會說
  歡迎回來；說「晚安」之後牠真的會去睡覺（閉眼、冒 Zzz、偶爾說夢話），隔天早上才醒。
  想叫醒牠：跟牠說話，或是連點牠三下。
- **好幾天沒來**：牠會跟你說想你了。
- **牠記得很久以前的事**：聊過的每一句話都會永久保存。你提到以前聊過的東西（例如「拉麵」），牠有時會想起來：
  「你之前說過最喜歡豚骨拉麵對吧？」
- **🔮 今日占卜**：右上角天氣旁邊的按鈕，結果會蓋在角色上面，按 ✕ 關閉。一天抽一次（再按是再看一次同一個結果），有運勢、幸運色、
  幸運物、幸運數字。
- **節日**：聖誕節、新年、情人節、七夕、中秋節、萬聖節、賞櫻季…（台灣跟日本的節日都有），
  畫面會有飄雪、櫻花瓣之類的裝飾，牠也會戴上應景的帽子，聊天時會祝你節日快樂。
- **親密度**：常常聊天、摸摸牠，親密度會慢慢升級（最高第 6 級「家人」）。等級越高，牠說話越親近，
  也會學會新的反應。可以在📔日記本最上面看到現在的等級。
- **牠自己的小動作**：閒著的時候偶爾會打噴嚏、打呵欠、哼歌、東張西望，吃飯時間還會偷吃飯糰；熟一點之後會自己跳舞。
  聊到吃的，牠講完話會吃一口點心；聊到音樂、唱歌、跳舞，牠會跳一段舞。一直戳牠會頭暈。睡覺時會戴睡帽。
- **衣櫥 👗**（全身的樣子才有）：上方的 👗 可以幫角色換穿搭，分成頭（帽子、髮飾）、脖子、衣服、臉（眼鏡）四個部位，可以混搭。
  選好按「就穿這樣！」，角色會開心地說一句話；每個角色各自記得自己的穿搭，聊天時問牠穿什麼也答得出來。
  每個部位預設是「自動」：春天小花冠、夏天草帽、秋天貝雷帽、冬天圍巾，節日當天換成應景的帽子；自己選了某件就一直穿那件。
- 白天晚上背景會不一樣，晚上 PokkaTomo 會呈現想睡覺的樣子。
- 視窗拉大拉小都可以：瀏覽器開得很寬時，角色在左邊、聊天在右邊；視窗窄的時候會自動改成上下排。

## 常見狀況

**要把問題告訴開發者**
⚙️設定 →「⬇️ 匯出所有資料」，把下載的 zip 檔傳給開發者。裡面有紀錄檔（`logs`），記錄了哪裡出錯、牠想了多久，
紀錄檔本身不含聊天內容（但 zip 裡的「對話紀錄.txt」有，介意的話可以先刪掉那個檔案再傳）。

**PokkaTomo 好像沒反應、卡住了**
送出訊息後底下會先出現跳動的「…」表示牠在想；如果想比較久會換成文字提示，這是正常的，
不是壞掉。如果真的失敗了，訊息旁邊會有「重新傳送」按鈕，點一下再試一次就好。

**語音沒辦法用**
語音輸入建議用 **Google Chrome** 開這個網頁才會穩定；如果瀏覽器不支援語音輸入，
畫面會自動改成打字輸入框，不會卡住沒辦法用。Safari 通常聽得到 PokkaTomo 說話，
但可能沒辦法用麥克風跟牠說話。如果按住麥克風後 PokkaTomo 跳出泡泡說沒收到聲音或沒拿到權限，
照泡泡說的做就好（例如去瀏覽器設定允許麥克風），或直接改用⌨️打字。

**換電腦、或資料壞掉想還原**
⚙️設定 →「⬆️ 匯入備份」，選之前「匯出所有資料」存下來的 zip，輸入密碼確認。所有角色的對話、日記、設定會換成 zip 裡的；
現在的資料會先另外存一份，不會不見。密碼維持現在這組。

**右上角出現紅色三角形驚嘆號**
代表有狀況，按一下會顯示是什麼問題。如果是「牠在發呆、暫時沒辦法聊天」：
通常是這台 Mac 的 Apple Intelligence 還沒準備好，或者剛啟動還在檢查。網頁不會壞掉，
等一下狀況變好的話驚嘆號會自己消失，不需要重新整理頁面。

**想換 PokkaTomo 的個性、稱呼或紀念日**
點右上角⚙️打開設定面板，改完按儲存就好，不用碰任何檔案。

**想用 iPhone／iPad 聊天**
在 Mac 上打開 ⚙️設定 → 最下面的「手機／平板連線」打勾，畫面會出現兩個 QR code（手機要連同一個家裡的 Wi‑Fi）：
- **① 每台手機／平板第一次（只要一次）**：用相機掃第一個 QR code，**用 Safari 打開**，照畫面上的步驟安裝「PokkaTomo Home CA」憑證，
  再到「設定 → 一般 → 關於本機 → 憑證信任設定」把它打開。這張憑證是這台 Mac 自己做的，只用在家裡的連線。
- **② 開始使用**：掃第二個 QR code（`https://` 開頭），Chrome、Safari 都可以。可以「加入主畫面」，之後直接點圖示。
- 手機上也能**按住說話**：錄好的聲音傳到 Mac，用 macOS 內建的語音辨識轉成文字（盡量在 Mac 上辨識，不用上網）。
  第一次打開這個功能時 Mac 會自動準備（需要「Xcode 指令列工具」，一兩分鐘），並跳出「是否允許 PokkaTomo 語音辨識」，請按「好」。
  設定面板裡會顯示「手機上可以按住說話」；有問題時那裡會說要怎麼做。
- Mac 睡著、或 PokkaTomo 沒開的時候連不到。第一次打開時 Mac 可能會問要不要允許連線，按「允許」。
- 沒打勾的時候，只有這台 Mac 自己能打開，同一個 Wi‑Fi 的其他裝置都連不進來。

**聊天紀錄、日記存在哪裡？怎麼備份？**
全部都存在這台 Mac 上，不會上傳到網路：資料夾裡的 `server/data/`。
- 每一句對話都會永久保存（`archive` 資料夾），不會因為聊太多被刪掉。
- 每天第一次打開 PokkaTomo 時，會自動備份一次（`backups` 資料夾，保留最近 14 天）。
- 想另外存一份到隨身碟或雲端：⚙️設定 → 最下面「⬇️ 匯出所有資料」，會下載一個 zip 檔，
  裡面的「對話紀錄.txt」「日記.txt」直接打開就能看。
- 換電腦時，把 `server/data` 整個資料夾放回新資料夾的同一個位置就好。
更新程式時不要刪掉或覆蓋這個資料夾。

**用什麼瀏覽器開？**
雙擊 `start-pokkatomo.command` 時，如果電腦有 Google Chrome 就會自動用 Chrome 開（按住說話最穩定）；
沒有 Chrome 才會用 Safari。建議安裝 Chrome。

## 需求

- macOS 版本要支援 Apple Intelligence，不然 PokkaTomo 沒辦法回話（但畫面上會清楚告訴你為什麼）。
- 建議安裝 **Google Chrome**（啟動時會自動用它開），語音輸入才會穩定。
- 需要先安裝過 [Node.js](https://nodejs.org/)（LTS 版本即可，需要 20 以上），只需要裝一次。
